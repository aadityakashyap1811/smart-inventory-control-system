# 📦 Enterprise Smart Inventory Control System

An interactive, data-driven inventory management and analytics dashboard designed to monitor stock levels, automate reorder alerts, and optimize supply chain operations across multiple industry verticals.

---

## 🚀 Key Features

- **Dynamic Inventory Tracking:** Real-time stock status monitoring across diverse product categories and sectors.
- **Automated Reorder Thresholds:** Algorithmic calculation of minimum safety stock and dynamic reorder alerts.
- **Interactive Visualizations:** Built with Plotly to deliver intuitive distribution charts, demand trends, and operational metrics.
- **Industry Simulation:** Pre-configured datasets simulating realistic enterprise-scale inventory environments (50+ companies).

---

## 🛠️ Tech Stack

- **Language:** Python
- **Framework:** Streamlit
- **Data Manipulation:** Pandas
- **Visualization:** Plotly Express
